# 프런트·Java 서버 상세 주석과 개발자 읽기 안내

2026-10-09 요청: JSP·Java 경험이 있는 개발자가 Vue 3·TypeScript를 처음 읽어도 모든 화면과 기능의 흐름을 이해할 수 있도록 상세 주석을 유지한다. 사용자가 Java 서버도 같은 대상으로 명시했다.

## 적용 기준

- SFC의 template 영역과 script에 역할·자료 원본·props/emit·이벤트 흐름을 설명한다.
- API/schema/query/composable에서 타입과 실제 검증, 캐시 키, 오류 매핑, session generation/선택 epoch, 자원 정리 이유를 설명한다.
- Java Controller/DTO/Service/Entity/Repository/설정/SPI에서 업무·권한·revision·트랜잭션·외부 연동·메시지 ACK·복구 경계를 설명한다.
- 단순한 줄 번역을 반복하지 않고, 구현과 연결된 설명을 작성한다. 코드 수정 시 설명도 함께 갱신한다.
- [개발자 읽기 안내](../developer-reading-guide.md)를 README·구조·유지보수 문서에 연결하고 루트/v2 AGENTS에 향후 주석 기준을 추가한다.

## 검증 기록

검증은 신규 임시 자료와 별도 포트를 사용한다. 실제 개발 서버의 DB·계정은 검증에 사용하지 않는다. 이전 디자인 검증의 통과 수를 이번 작업에 합산하지 않는다.

- [x] 공개 UI 계약 25개의 props/events/slots/default 비교: 일치.
- [x] Java 201개 토큰 비교 차이 0, 전체 434개 적용 누락 0. [범위/해시/Java 검사](../검증/comment-guides/coverage-and-java.json)·[프런트 검사](../검증/comment-guides/frontend-semantic-check.json).
- [x] `bash scripts/build.sh` 최종 통과: npm ci·format/lint/API·UI 계약·typecheck·unit 167/40 files·frontend build·Maven clean verify. 서버 총 196개 중 193개 실행 성공, 외부 RabbitMQ 3개 skip. [통합 로그](../검증/comment-guides/integration-build.log)·[서버 집계](../검증/comment-guides/backend-tests.json).

[E2E 로그](../검증/comment-guides/e2e.log).
- [x] v2 변경 파일 45개의 checksum 갱신. `npm run starter:generator:verify -- --report .runtime/comment-guides/generator-summary.json` 50개 경계 검사 통과. 실제 artifact 설치/생성 앱 재빌드는 수행하지 않았다. [생성기 결과](../검증/comment-guides/generator-summary.json).

초기 임시 의미 비교 도구에서 Vue compileScript가 가져온 props 타입을 해석할 filesystem adapter가 없어 검사 오류가 발생했다. 제품 컴파일 실패가 아니며, 비교 방법을 원본 TypeScript AST(타입 포함)와 주석 없는 template 렌더 코드로 명시했다. 실제 컴파일은 정식 typecheck/build에서 별도로 확인한다.

첫 통합 빌드는 unit 167개 중 13개가 실패했다. template 최상위 형제 HTML 주석이 개발 모드의 단일 루트를 Fragment로 바꾸어 wrapper 속성/클래스 검사에 영향을 줬다. 136개 SFC의 최상위 화면 설명을 script 블록 주석으로 옮기고 테스트 코드는 그대로 유지했다. 개발 규칙과 안내서에도 이 위치 규칙을 추가했다. 수정 후 unit 167개 전부 통과하고 위 최종 통합/Story/E2E 검증도 통과했다. [초기 실패 로그](../검증/comment-guides/integration-build-first-failed.log)는 그대로 보존한다.

시각 기준 이미지는 갱신하지 않는다. 실제 사용자 디자인 수락, 이전 전체 운영 인프라/RabbitMQ 회귀, 모든 외부 소비 앱의 재설치·실행은 이번 주석 변경의 검증 결과로 주장하지 않는다.

주석 내용은 별도 담당자가 실제 코드와 대조했다. 상태 소유자·가상 목록·서버 페이지·타입명 등 표현 5건과 안내서의 트랜잭션 시작 위치·epoch 용어 2건을 정정했다. 테스트 코드는 변경하지 않았다. 전체 변경은 주석과 안내/규칙/템플릿 해시이며, 업무 실행 코드 차이는 없다.
