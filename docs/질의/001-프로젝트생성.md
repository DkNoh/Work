중립 레퍼런스 예제는 `/api/examples`의 title 저장·목록·revision 충돌이다. 업무 API 계약을 추출하기 전에 재사용 모듈의 HTTP·폼·DB 경계를 검증하기 위한 예제다. 최소 Starter 앱은 이 업무 코드를 import하지 않는다.

OpenFeign은 서버에서 외부 HTTP API를 호출하는 도구다. Vue 브라우저 요청의 Axios를 대체하지 않는다. client 목록·URL·connect/read timeout·오류를 명시하고 수신 cookie/CSRF를 자동 전달하지 않는다. 실제 외부 서비스 없이 loopback 서버로 검증한다. [OpenFeign 4.3 공식 안내](https://docs.spring.io/spring-cloud-openfeign/reference/4.3/spring-cloud-openfeign.html).

springdoc FAQ의 Boot 3.5 표는 2.8.x를 안내하지만 실제 2.9.1 태그의 부모가 Boot 3.5.16인 것을 확인했다. 001은 2.9.1을 고정하고 실제 명세·UI 기동을 검증한다. [정확한 springdoc POM](https://raw.githubusercontent.com/springdoc/springdoc-openapi/v2.9.1/pom.xml), [Spring Cloud BOM](https://raw.githubusercontent.com/spring-cloud/spring-cloud-release/v2025.0.3/spring-cloud-dependencies/pom.xml).

단계별 실제 결과는 `docs/검증/001-*`에 남긴다. 설치·코드 생성·실행 검증을 구분하며 미완료가 있으면 실패/제한을 그대로 기록한다. 다음 단계는 [002~012 계획](개발단계.md)과 [레퍼런스 설계 문서](../../../WorkboardVue/docs/질의/개발가이드.md)를 따른다.

접근성 최초 실행은 8개 중 6개 통과·2개 실패였다. 로딩 progressbar의 이름과 읽기 전용 floating label 대비를 수정하여 8개 전체를 다시 통과했다. 라벨 대비는 4.23에서 5.09:1로 개선했다. [초기 실패](../검증/001-storybook-tests-initial.log), [측정 근거](../검증/001-storybook-readonly-contrast.json), [읽기 전용 화면](../검증/001-storybook-readonly.png)을 보존한다. 검사 규칙을 제외하지 않았다.

기초 Reference 화면의 1366/390 폭 검수 자료는 [실제 화면 확인](../검증/001-reference-visual.json), [desktop](../검증/001-reference-desktop.png), [mobile](../검증/001-reference-mobile.png)에 둔다. 이 캡처는 002의 전체 디자인·1920 폭·모든 상태 검수를 대신하지 않는다.

초기 Swagger 설정이 무시되던 실패, 401/403 테스트 가정 오류, lint 누락도 별도 기록을 보존했다. 최종 gate가 통과한 결과와 구분한다. Storybook 정적 docs 번들의 500KB 경고는 남아 있으며 번들 최적화는 이후 카탈로그 단계에서 다룬다. `npm ci` 뒤 `npm ls --depth=0`은 종료 0이지만 Sass의 optional 하위 패키지 4개를 extraneous로 표시한다. 해당 항목은 lock에 존재하며 재현 설치·두 앱·Storybook 빌드는 통과했다. [실제 npm 목록](../검증/001-npm-ls.json)에 표시를 보존한다. 이 기록을 의존성 경고가 전혀 없다는 의미로 해석하지 않는다.

Vite 파일 차단 보완 후에도 `npm run verify`를 다시 통과했다. [최종 프런트 검증](../검증/001-frontend-verify-final.log)과 [JAR/최종 dist 바이트 비교](../검증/001-jar-assets.json)에서 두 앱의 각 3개 파일이 모두 일치했다. CI/Compose YAML은 parser로 확인했으며 [구문 결과](../검증/001-yaml.json)에 원격 실행 여부를 구분했다.
