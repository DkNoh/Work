값은 [디자인 문서](디자인.md), 실제 경로는 [폴더 구조](../folder-structure.md), 변경 방법은 [유지보수 가이드](../maintenance-guide.md)를 따른다. 본문 14px/제목 24px, 버튼·입력 6px/카드 8px/일반 대화상자 정책 12px, sidebar 248px/content 최대 1280px, breakpoint 768/1200/1600/1920px를 원본에 정의했다. 전체 높이 모바일 drawer는 직각이며 일반 대화상자 래퍼는 003 이후 계약과 구분한다.

셸은 메뉴 권한·업무 URL·세션·HTTP·폼을 소유하지 않는다. 앱은 `{id,label,href}` 메뉴와 Router에서 계산한 `activeItem`을 전달하고 `navigate`를 Router에 연결한다. UI 파일/import `Sc...`, template `sc-...`, CSS `.sc-*`를 유지한다. 페이지는 셸의 단일 `main`에 `section`으로 들어간다.

헤더의 최소 높이 64px 토큰은 유지하면서 긴 제목으로 커지는 실제 높이는 셸의 로컬 `--sc-shell-header-height`로 측정한다. sidebar top/min/max-height는 이 측정값을 사용한다. 모바일 dialog는 Escape keydown으로 명시적으로 닫고 native focus 복귀를 이용한다. 양 끝 Tab·Shift+Tab을 명시적으로 순환시키고, 화면 전환으로 숨겨지는 탐색의 focus도 보이는 링크/버튼으로 이동한다. Observer·media query listener 해제와 두 앱의 작성 중 입력 보존까지 검증했다. 공개 `@sc/ui/tokens`로 소비 앱과 UI 내부 폴더의 결합을 제거했다.

## 순서·완료 조건

1. primary #21647a를 출발점으로 의미별 색상·글꼴·간격·반경·그림자·breakpoint를 정리한다. `tokens.ts`를 단일 원본으로 삼고 생성 CSS·Vuetify·문서·카탈로그가 같은 값을 사용한다.
