# 003 — 공통 UI 공개 계약

상태: **003 구현·로컬 검증 완료**. 002의 토큰·셸을 출발점으로 공개 타입과 props·이벤트·slot·HTML 속성의 경계를 정리하고 실제 두 앱 빌드·새 JAR·관련 단위/Storybook·브라우저 검증을 확인했다. 공개 사용법은 [UI 공개 계약](UI-공개계약.md)에 둔다. 마지막 문서 편집 후 format/lint와 최종 정적 카탈로그 재확인은 별도 마감 확인으로 남긴다.

기존 두 소비 앱과 Storybook의 사용처를 유지한다. 005의 표·가상화·차트·Excel·리치텍스트·다국어와 011의 외부 배포·생성기까지 구현한 것으로 표시하지 않는다.

| 순서 | 작업                                                                                 | 완료 조건                                                                   |
| ---- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| 1    | ScActionButton/ScTextField/ScAppShell의 공개 props·기본값·emits·slot·attrs 책임 기록 | 실제 소스·타입·카탈로그가 일치하고 내부 Vuetify 속성을 무제한 공개하지 않음 |
| 2    | 입력·readonly·disabled·busy·error·label·focus·HTML form 계약 확인                    | 공개 model/event 결과·중복 저장 방지·필드 오류·접근성 이름의 의미 검증      |
| 3    | 셸 메뉴·Router·세션·업무 폼 경계 유지                                                | 공통 패키지가 소비 앱을 import하지 않고 두 앱에서 동일 계약 소비            |
| 4    | package exports·styles·tokens 공개 경계 검사                                         | 앱이 UI 내부 상대 경로를 참조하지 않고 실제 Vite 빌드 성공                  |
| 5    | Storybook Autodocs/사용 예제와 변경·폐기 정책 기록                                   | 공개 계약을 문서로 확인하고 관련 기능/a11y·두 앱 JAR E2E 통과               |

외부 npm bundle/pack과 빈 경로 생성기는 011에서 검증한다. UI 계약은 실제 두 사용처와 필요한 상태를 기준으로 정하며, 저장·권한·Query 키를 공통 부품에 넣지 않는다. [전체 구현 대상](조건부기술-전체구현.md)은 모두 후속 단계에서 구현하고 Redis·JWT·SSO는 제외한다.

## 통합 확인 항목

- [x] 공개 Props/Emits/Slots와 값 타입을 `@sc/ui`에서 import하고 소비 앱의 타입 검사가 통과한다.
- [x] 기본값·지원 HTML/ARIA/data 속성·전달 위치·지원하지 않는 Vuetify 속성이 문서와 소스에 일치한다.
- [x] 버튼의 기본 type·submit/reset·busy/disabled·click 및 입력의 model·readonly/disabled·오류/설명·native form 계약을 확인한다.
- [x] 셸 메뉴의 readonly 계약·navigate·slot·앱별 Router와 세션 소유권을 유지한다.
- [x] 두 앱·카탈로그가 공개 export/styles/tokens를 소비하고 UI 내부 경로를 참조하지 않는다.
- [x] 형식/lint/타입/관련 단위·Storybook 기능/a11y·앱 빌드·최신 JAR E2E 결과를 기록한다.
- [x] 최초 실패와 수정·남은 작업을 보존하고 실제 확인한 항목만 완료 표시한다.
- [x] 003/004 마감 문서의 최종 형식 검사를 [004-docs-format.log](../검증/004-docs-format.log)로 확인했다. 진행 중인 005 source의 검증과 구분한다.
