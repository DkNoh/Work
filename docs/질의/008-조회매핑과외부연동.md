6.12 태그는 Boot3.5/Hibernate6.6/JPA3.1/H2/JDK21을 기준으로 관리했다. 현재 프로젝트의 Hibernate6.6.53 조합은 최종 서버77개와실제 runtime6.12 확인에서 통과했다. 최신 fork 7.x의 Boot4/Hibernate7/JPA3.2 기준을 이 프로젝트에 그대로 적용하지 않는다. Querydsl fork의 Java package는 `com.querydsl`이며 외부 HTTP OpenFeign client와는 역할이 다르다. [6.12 공식 POM](https://raw.githubusercontent.com/OpenFeign/querydsl/6.12/pom.xml), [Jakarta processor](https://raw.githubusercontent.com/OpenFeign/querydsl/6.12/querydsl-tooling/querydsl-apt/src/main/java/com/querydsl/apt/jpa/JPAAnnotationProcessor.java).

Boot는 provided도 실행 JAR에 포함하므로 Lombok을 repackage에서 명시 제외한다. [MapStruct/binding](https://mapstruct.org/documentation/stable/reference/html/#_lombok), [Compiler3.14.1](https://maven.apache.org/plugins-archives/maven-compiler-plugin-3.14.1/compile-mojo.html), [Boot packaging](https://docs.spring.io/spring-boot/3.5/maven-plugin/packaging.html).

Querydsl/MapStruct는 Apache2.0, Lombok/binding은 MIT다. 직접 POM·실제 JAR 의존성과 생성 산출물로 버전을 확인했다. [Querydsl POM license](https://raw.githubusercontent.com/OpenFeign/querydsl/6.12/pom.xml), [MapStruct license](https://github.com/mapstruct/mapstruct/blob/1.6.3/LICENSE.txt), [Lombok license](https://github.com/projectlombok/lombok/blob/v1.18.46/LICENSE).

## 책임과 계약

단순 findById·조회·CRUD는 JPA Repository에 둔다. Querydsl 목록의 q/menu/status/author/screenVersion과 DRAFT 공개 조건은 list/count가 같은 predicate를 사용한다. 정렬은 updatedAt DESC,id DESC이며 page/size/문자 검색 `% _ \`의 기존 계약을 유지한다. 목록별 이름 조회의 N+1 개선과 복잡 join/집계/성능은 009 MyBatis 보고에서 검증한다. 동일 API를 두 조회 엔진으로 상시 중복 실행하지 않는다.

공통 ScQuerydslAutoConfiguration은 Hibernate JPA 준비 뒤 단일 또는 primary EntityManagerFactory를 선택하고 트랜잭션에 결합되는 SharedEntityManager proxy로 factory를 제공한다. 다중 DB에서 선택이 모호하면 기본 factory를 생성하지 않으며 소비 앱의 JPAQueryFactory bean으로 교체할 수 있다. 앱의 DTO/Entity/권한 predicate를 공통 모듈로 가져오지 않는다.

MapStruct는 numeric similar0/1·nullable reviewer/관계·빈 배열·UTC Instant.toString·history JSON 문자열을 보존하는 읽기 변환이다. 이름은 Service가 인자로 전달한다. revision·상태 전이·actor·쓰기·clock·audit·history 원자성은 기존 Service가 소유한다. DTO에서 Entity로의 inverse mapping은 제공하지 않는다.

공통 FeignCallBoundary는 network/timeout RetryableException을 기존504 UPSTREAM_TIMEOUT, FeignException을502 UPSTREAM_FAILURE로 변환한다. 외부 URL·응답 본문·예외 message/cause를 공통 API 오류에 포함하지 않는다. 앱 고유 업무 오류는 이 경계가 다시 해석하지 않는다. 소비 앱의 bean/Retryer/requestId interceptor override를 허용한다. ReferenceEchoClient의 명시 등록·URL과 기존 API를 실제 소비 예제로 유지한다.
