# 012 — 선택 운영 모듈과 독립 Starter 마감

**001~012 기능 구현·로컬 통합 검증 완료**. 사용자 지정 Yzen Sales의 시각 목표는 기존 UI가 충족하지 못했으며 별도 [디자인 교정](디자인교정.md)의 로컬 구현·검증을 완료했다. unit149·서버196 등 이 문서의 결과는 기능 마감 당시 실제 근거로 보존한다. [새 디자인 교정 QA](../검증/design-correction-final-summary.json)는live40검사/전체DOM14회 위반0·unit155/선별서버10·새JAR관련30고유 케이스·정적파일46/8해시·원격프리뷰 로그인까지 확인했다. 이 문서의012 성적을 재작성하지 않는다. 새 시각 기준16PNG의 명시 갱신·정상 비교4개와 전체 Storybook105개/30files도 통과했다. 새패키지 외부설치소비는 미확인이며 사용자 디자인 수락은 `accepted=false`다. [최종 집계](../검증/012-final-summary.json)에 기존 실제 검사와 범위 metadata를 구분한다. 이전 단계의 숫자와 이번 단계의 숫자를 합산하지 않는다.

전체 [Storybook105개/30files](../../.runtime/design-correction/storybook-all-resize-final.log)와 새 [시각 비교4개](../../.runtime/design-correction/visual-baseline-compare.log)가 통과했다. 이전104PASS/1FAIL과 새 기준의 명시 갱신·교정 전17파일 보존은 디자인 교정 문서에 기록했다. 자동 로컬 검증 완료와 사용자 디자인 수락은 구분한다.

공통 프런트5패키지는 `0.3.0`, 서버 공통은 `0.3.0-SNAPSHOT`, 생성 templateVersion은2다. Vue3·Vuetify·SCSS·VueUse·TanStack Vue Query·VeeValidate/Zod·Prettier와 Spring Boot·JDK21·H2·JPA/MyBatis·Swagger/OpenAPI·OpenFeign을 사용한다. 자체 공통 UI는 `ScActionButton` / `<sc-action-button>` / `.sc-*`를 따른다. Redis·JWT·SSO는 제외한다. Yzen은 디자인 참고이며 코드·에셋·라이선스를 반입하지 않는다.

## 발견한 문제와 수정

첫 운영 브라우저4PASS/6FAIL, 두 번째7PASS/3FAIL, 세 번째8PASS/2FAIL과 결과 PNG/JSON을 보존한다. 제품의 선택/발생 이력 accessible name과 E2E의 PULSE UNIQUE·dialog/locale 대기를 수정한 뒤 fourth10PASS를 확인했다. 마지막 실제 PNG 검수에서 긴 UUID의 인접셀 겹침을 발견해 앱 전용 OperationsTable에 `table-layout:auto`를 적용했다. fifth10PASS와 독립 소비 앱의 실제 셀 geometry로 이 수정만 재확인했다. 공통 패키지·업무 API·권한·DB 계약은 이 시각 수정으로 바꾸지 않았다.

독립 소비 앱의 최초 generator provenance는 보존했다. ARIA/CSS 수동 수리는 별도 repair JSON에 기록했다. 최종 fresh 생성의 BrowserPanel bytes는 실행한 수리 앱과 같고 OperationsTable은 독립 CSS 선언 순서만 다르며 전체 소스 동등성을 확인했다. fresh 생성 경로에서 자체 install/build를 다시 실행했다고 주장하지 않는다. 최초 독립 앱의 서버10·Notes/운영 API와 최종 브라우저 실행 증거를 각각 따른다.

최종 Docker gate 최초 실행은 PATH에 `/usr/local/bin`이 없어0그룹에서 `SC_DOCKER_CLI`로 중단됐다. [실패](../검증/012-docker-operations-final.json)를 보존하고 경로 교정 뒤 동일 검증기7그룹이 통과했다. 제품 수정·검증 범위 확대는 없었다. 검증용 task Compose 컨테이너는 종료하고 volume과 private 설정은 보존한다.
