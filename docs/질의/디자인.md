## 공통 셸과 반응형

[ScAppShell](../../frontend/packages/ui/src/layout/ScAppShell.vue)은 header·sidebar·본문·모바일 탐색을 제공한다. [ScShellNavigation](../../frontend/packages/ui/src/layout/ScShellNavigation.vue)은 셸 내부 부품으로 같은 링크 구조를 재사용하며 공개 export에 포함하지 않는다. 메뉴의 현재 항목은 `aria-current="page"`와 배경/선으로 함께 표시한다. 일반 클릭은 `navigate`로 앱에 전달하고 Ctrl/Meta 등 새 탭 동작은 유지한다.

Reference와 Starter는 같은 셸을 소비하지만 메뉴·현재 route·세션·로그아웃은 각각 앱이 소유한다. Reference는 로그인 전/후 실제 route만 표시하고 Starter는 자체 시작 route만 가진다. 미구현 통계·장식 행동·업무 메뉴를 추가하지 않는다. 셸의 `default`·`header-actions`·`notice`·`sidebar-footer` slot으로 내용을 조립하며 업무 HTTP나 폼 규칙을 셸에 넣지 않는다.

768px 미만에서는 sidebar 대신 탐색 버튼으로 native `dialog`를 연다. 768px 이상에서는 sidebar를 표시한다. 단일 `main`과 고유 ID를 쓰는 본문 skiplink, dialog의 접근성 이름·열기/닫기·Tab·Escape·focus 복귀를 검증한다. Escape는 명시적인 keydown 처리로 닫으며 native dialog의 focus 복귀와 함께 사용한다. 업무 페이지 root는 `section`으로 두어 main을 중첩하지 않는다. 어두운 탐색의 focus는 흰색, 밝은 본문의 focus는 어두운 청색을 사용한다.

전체 breakpoint는 768/1200/1600/1920px지만 모든 화면에 같은 열 수를 강제하지 않는다. 예제 목록·입력은 viewport 대신 실제 본문 폭의 container query로 920px 미만에서 한 열이 된다. 390/1366/1920px에서 긴 한국어와 조작 영역·가로 넘침을 확인한다. 헤더의 디자인 최소 높이는 64px다. 긴 앱 제목·계정 영역·폭 변화로 높이가 커지면 `ResizeObserver`가 실제 높이를 셸 내부 `--sc-shell-header-height`에 반영하며 sidebar sticky 위치와 높이는 이 값을 따른다. 측정값은 컴포넌트 상태이고 토큰 원본을 변경하지 않는다. 화면 전환으로 탐색 영역이 숨겨지면 focus를 현재 desktop 링크 또는 모바일 열기 버튼으로 이동한다. Observer와 media query listener는 unmount에서 해제한다. 실제 배치는 [002 결과](002-디자인토큰.md)와 화면 캡처로 확인했다.

002의 다국어 확장점은 앱이 제목·메뉴·slot 문구를 전달하는 경계다. skiplink·탐색 버튼·Vuetify locale는 현재 한국어다. Vue I18n 설치·공통/업무 메시지 분리·한국어/영어 전환·fallback·누락 키·Vuetify 연결은 [조건부 전체 구현](조건부기술-전체구현.md)의 005에서 실제 구현한다.

## 009 실제 보고서 디자인과 시각 검수
