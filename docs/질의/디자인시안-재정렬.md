# Yzen 시안 재정렬 — 공통 프레임워크 후보

2026-10-09 사용자가 [Yzen Vue Sales](https://projects.spruko.com/vue/yzen/preview/dashboard/sales)를 원본 시안으로 재확인했다. 기존 화면이 탁하고 현대적이지 않다는 피드백에 따라 공통 글꼴·강조색·카드와 대표 대시보드를 조정했다. 프런트/백엔드 모두 개발자가 업무 기능을 안정적으로 추가할 수 있는 판매용 공통 프레임워크라는 목표를 유지한다. 사용자 디자인 수락은 `false`다.

## 적용 경계

프런트의 색·타이포·카드·셸은 `@sc/ui`, HTTP·세션·CSRF·공통 오류는 `@sc/runtime`이 소유한다. Reference와 최소 Starter는 공통 모듈을 소비한다. 대시보드의 메뉴·자료·그리드·조회 기간·CSV는 앱의 기능 폴더가 소유한다. 서버 core/autoconfigure/starter와 앱 Service·DTO·migration의 기존 책임 구분은 유지한다. 이번 변경은 디자인과 UI 소비 검증이며 서버 공통 API의 새 기능 구현을 포함하지 않는다.

## 변경한 규격

| 영역         | 이번 후보                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| 글꼴         | Plus Jakarta Sans의 공식 공개 라이선스 가변 WOFF2 자체 제공. 숫자/라틴 글꼴을 통일하고 한글은 시스템 fallback 사용 |
| 색           | 선명한 본문 `#111827`, 읽기 쉬운 보조색 `#59677c`, 원본의 녹색·보라·분홍·황색 강조색과 파스텔을 중앙 토큰으로 제공 |
| 색의 책임    | 강조색은 그래프·장식에 사용. 작은 글씨/버튼의 의미색은 대비를 유지. KPI 두 밀도에 같은 tone 팔레트 적용            |

| 대시보드     | 1440px 본문 x252/좌측 876px/우측 276px/차트 576px. 간격 24px, 샘플 출처를 제목 설명 행에 통합                      |

| 실제 행동    | 기간/자료 선택은 Router, 실제 보고서는 기존 Query/API. 표 CSV와 차트 CSV를 각 데이터에 연결                        |
| 공통 예제    | Storybook FourMetrics의 density Controls가 모든 카드에 실제 적용되며 개별 tone은 유지                              |

Yzen의 제품 코드·폰트 파일·브랜드·이미지를 복사하지 않았다. Plus Jakarta Sans는 공식 Google Fonts 공개 배포본이며 OFL 원문을 소스·배포 CSS·`dist/fonts/OFL.txt`에 포함한다. 업무용 아이콘은 기존 `@mdi/js`를 사용한다. 글꼴은 앱/패키지에 포함되어 외부 폰트 서버에 요청하지 않는다.
